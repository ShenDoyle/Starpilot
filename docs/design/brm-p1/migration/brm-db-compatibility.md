## 1. winlease 文件迁移策略

| 文件状态 | brm.db 时代的行为 |
|---|---|
| 健康且属当前 run | 迁移导入 leases 表（原 lease_id/fencing 保留）；此后该文件只读 |
| 健康但属旧 run | 同上导入；授权判断只看库 |
| 损坏（JSON 解析失败/截断） | **不导入**；对应 instance 活跃资源 → OWNER_UNKNOWN；文件移入备份目录（不删） |
| 缺失 | 同「损坏」：不视为无主（裁定原文：损坏、缺失、不可解析 ≠ 没有所有者） |
| 旧版本字段（无 fencing/pid_start） | 导入但 fencing 取 instance 基线重排；缺字段本身不构成无主证据 |

库为权威后 winlease 文件的三项残余用途：① 进程级快速路径缓存（读优化）；② 迁移期兼容旧代码路径的观察样本；③ 故障取证。**不得独立授权资源操作**（裁定原文）——wa.py 中所有「凭文件判断放行」的分支在实施轮移除。

## 2. 旧 HMAC 票据（v5.1 gate_issue/gate_redeem）

- 迁移完成时统一作废：`gate-tickets/` 目录整体移入备份（不删），`gate.key` 轮换（新密钥 = 旧票全部验签失败）。
- shim 计数层以迁移时刻为新纪元，计数账本重置并记审计。
- 票据**不得成为绕过账本检查的通道**（裁定）：实施后 shim 的票据兑换只影响计数提示，wa.py 侧无论有无票都必须过账本门。测试计划含「持有效票但账本拒绝 → 必须拒绝」用例。

## 3. shim 与多安装位

| 场景 | 策略 |
|---|---|
| 旧 fail-open shim 在位（现状 4087B） | 不在本轮升级（禁令）；实施轮统一重装。在其之前，wa.py 直连真身本就绕过 shim，账本门不受影响 |
| `env.py --install` 重装官方 BSK | shim 失效属已知边界；账本门在 wa.py 内部，不受影响 |
| 直接调用 `bsk.bin.exe`（脚本/人） | 无法代码禁止（绝对路径自备）；shim 定位=提示+计数（v7 裁定），强制力来自账本+单一入口纪律；**特别审查 #2 已确认目前无绕过调用点**，留审计：账本可对「无认领记录的 session 出现动作」报警（reconcile 报告 orphan） |
| 旧安装位 `~/.workbuddy/skills/starpilot` | 迁移期间**不同步**（禁令）；实施轮后该安装位属「旧版本代码」，其行为不受 brm.db 保护——迁移设计中将「旧安装位清单」列为迁移前检查项，向用户报告后决定是否停用 |

## 4. IAB 通道隔离设计（P1-A 修订新增，v1.1，对应裁定）

裁定要点：IAB 最终必须接入统一资源账本；最后迁移可接受；**迁移前必须禁止未授权副作用**；独立浏览器实例也必须登记为资源；不得以使用量低为由豁免。

设计：

1. **登记义务（迁移前即生效的最低要求）**：IAB 会话启动时在 brm.db 登记 `sessions(state=ACTIVE, instance='iab-<profile-id>')`——独立浏览器实例同样是一种资源实例，与 bsk 实例同表同约束。裁定原文「不得用使用量低作为豁免理由」落实为：登记不是可选项。
2. **迁移前保护**：IAB 的 navigate/evaluate/fill/press 四动作在 op 队列入队前过导航门（navigate_gate 同款校验）；账本不可用 → 拒绝入队（fail-closed，与其他通道一致）。实施轮前的过渡期（账本未切换时）沿用现状并**禁用新增 IAB 任务**（设计建议，待裁定确认过渡策略）。
3. **迁移顺序**：IAB 排在 brm.db 切换后的第一个迁移工作包（「最后迁移」确认）；迁移内容 = op 队列 worker 接账本门 + IAB session 认领/释放走 claim_session/release 流程。
4. **不豁免声明**：使用量低只影响迁移优先级，不改变「必须接入」的结论；测试计划 BT 组含 IAB 通道的账本拒绝用例。

## 5. 兼容期判定矩阵（实施轮回归用）

| 输入 | 期望行为 |
|---|---|
| 库可用 + 文件健康 | 授权看库；文件仅缓存 |
| 库可用 + 文件损坏 | 正常授权（文件不影响判断） |
| 库不可用（任意原因） | **全部副作用拒绝**：navigate/evaluate/click/fill/send/clear/close/cancel/stop/window release（裁定：不只保护写业务数据） |
| 文件缺失 + 库无记录 + tabs 有活跃记录 | OWNER_UNKNOWN，禁写 |
| 旧票 + 库拒绝 | 拒绝（票不是通行证） |
| 旧票 + shim 旧版 | shim 提示层行为不变；wa.py 侧与 shim 无关 |
