# RUNBOOK · 反爬 / 风控升级

> **什么时候用这份**：`triage` rc=10（风控 / 验证码 / 掉登录）、页面出现人机验证、
> 限流弹窗、发送被静默拒绝（rc=15）、账号"变笨"、连续多次请求被 429/403。
>
> 核心原则：**反爬升级是平台侧的变化，不是我们代码的 bug。** 硬刚 = 加剧风控甚至锁号；
> 正确姿势是分级降速 + 换通路 + 该找人时找人。

---

## 1. 先分型（rc=10 是四件事，处置完全不同）

| 现象 | 类型 | 机器判据 |
|---|---|---|
| 弹滑块/点选/图片文字验证 | `captcha` | `risk_kind()` 命中验证码容器 / `captcha_src` |
| 弹"请求过于频繁 / 人数太多 / 稍后再试" | `rate_limit` | 文案命中 + 无输入框阻塞 |
| 跳到登录页 / 需要重新登录 | `login` | 页面出现登录表单，无 composer |
| 发送成功但回复恒为空 / 回复明显降质 | `silent` / `degraded` | rc=15，且 `msg_count` 涨、`reply_count` 不涨 |

## 2. 分型处置

### 2.1 `captcha` / 滑块 —— **只能找人**

```bash
python scripts/wa.py triage        # 把输出**原样**给人（含 risk 与页面文案）
```

- 立刻停：不重发、不刷新、不换 UA、不切隐身窗口。
- 等人做完验证 → `triage` 复核 → 确认 `verdict` 不再是 `risk_control` 才继续。
- **禁止**用脚本模拟点击验证码（既违平台条款，也必然失败并加重风控）。

### 2.2 `rate_limit` / 限流弹窗 —— 自己降速，不找人

1. 先关弹窗（Kimi 是 `data-testid=confirm-dialog-cancel`＝「我知道了」；点是，不是去升级）。
2. **换档**：模型/额度档位下调，或换同时段更空闲的平台（推荐顺序见 `web-ai-platforms.md`）。
3. **冷却**：同一平台 10 分钟内不再发；把这一轮的工作改成"本地侧可做的事"（整理证据、跑测试）。
4. 冷却后第一次发送前必须 `probe` 确认 `editor:true` 且无弹窗。

### 2.3 `login` —— 找人登录，不许脚本代登

- 停：任何"自动填账号密码 / 复用 cookie"的做法都禁止（凭证不进代码、不进对话）。
- 人登录后 `bind <同一个 url>` 接上，**不要 `--new`**（对话还在服务端）。

### 2.4 `silent` / `degraded`（rc=15）—— 换通路而不是硬刚

- 该平台静默拒绝：**换平台**（按 skill 的推荐顺序），或等 30 分钟。
- 账号"变笨"（回复明显降质）：换平台跑一轮，别在同一对话里反复追问同一件事。

## 3. 反爬"升级"了怎么办（Cloudflare / Turnstile 加严）

平台把防护升级后，症状通常从"能发但慢"变成"整页过不去"。识别与处置：

1. **判据**：`probe` 拿不到 composer，页面主体是一个 iframe / `challenges.cloudflare.com`。
2. **能做的**：用**用户真实浏览器**（bsk 绑用户已登录的实例）——这是本 skill 的默认形态，本来就是最强通行证；
   不新建无痕 profile、不切自动化指纹（越像机器人越难通过）。
3. **不能做的**：绕验证（第三方 solver）、伪造 UA/指纹、高频重试。
4. **升级后的长期对策**：把该平台在 `platforms.py` 标 `verified: false`，跑 `matrix` 看替代平台；
   平台矩阵的 `send_allowed` 会自动把它从可写清单里剔掉。

---

## 4. 输出要求（给人看的部分）

风控类问题**人必须能一眼接手**。报告里固定三行：

```
类型：<captcha|rate_limit|login|silent>
证据：<triage 输出的 risk/文案原文，不要转述>
要做的事：<人做什么，一句话；或"已自动冷却到 HH:MM">
```

## 5. 禁止动作

- ❌ 见验证码就重试（`rc=10` 重试 = 直接进风控名单）
- ❌ 刷新页面"试图绕过"（多数平台会加深挑战）
- ❌ 换 IP / 换 UA / 开代理池硬刚
- ❌ 把限流当"平台坏了"直接换平台（先关弹窗 + 降档，多数能救）
- ❌ 隐瞒风控继续跑（后面所有判据都不可信）
